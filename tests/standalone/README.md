# Standalone service

These are planned acceptance cases, not passing tests. Apply the [shared case requirements](../README.md) to each branch.

**The first vertical.** This journey is built first and runs without Pale or Buzz. A steward qualifies an account against recorded evidence, with the assessment keeping its checks, counterevidence and policy version. The assessment's proposed next action becomes work only through an explicit command that names an owner and acceptance conditions. The assignee submits a result, and the reviewer entitled to accept it does so; a reviewer whose authority was revoked, or a blocker added after validation, must produce a refusal or conflict instead. Each step recovers from a lost reply by its command identity.

**The complete standalone service.** Install `commercial-work` through the public Rust SDK alone, create, query and change records through REST and GraphQL, schedule a recurring work item, use the local conformance provider, watch the outbox and webhook, reconcile a commit-unknown and restore the instance, all without Pale, Buzz or Scope.
