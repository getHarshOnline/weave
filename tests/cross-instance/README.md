# Exchange between instances

These are planned acceptance cases, not passing tests. Apply the [shared case requirements](../README.md) to each branch.

**Two instances and a hosted adopter.** Absence, denial, duplication, a card crossing instances and unsupported contracts end in explicit safe states; correspondence without merging IDs or authority, keeping same person, same message and same content apart.

**Delivery between instances over the provisional HTTPS carrier.** Lost and duplicated webhooks recover through cursor pull and occurrence de-duplication; reusing an occurrence ID with changed content fails; changing anything at the destination needs its own authorised command; correspondence moves from candidate to local acceptance to mutual attestation without merging.
